# Inkling 英文日記教練

每天寫幾句日記，中英混寫都可以。AI 教練幫你改成自然的英文、說明每一處修改的原因，並自動整理成複習卡。

純前端 PWA，不需要後端，可以直接放在 GitHub Pages 上，用手機「加入主畫面」後就像一般 app。

## v0.1 功能

- **寫日記**：作文簿橫線紙面、每日題目、草稿自動保存、中英混寫
- **AI 批改**：自然版本全文（藍筆標出改動處）、逐處修改（刪除線／插入）、修改類型標籤、繁中說明、教練一句話
- **值得記下來的說法**：每篇挑 3–5 個單字或片語，附例句與朗讀
- **複習卡**：批改後自動建立，間隔重複（忘了／有點難／記住了）
- **日記本**：兩週打卡格、最近 30 天最常錯的類型、歷史日記
- **個人化**：最常錯的類型會回饋給 AI，下次批改時會特別提醒
- **設定**：英文程度（A2–C1）、批改方式（只改錯／改得更道地）、匯出／匯入備份
- **PWA**：可安裝、離線開啟、支援深色模式

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `inkling`）。
2. 把這個資料夾裡所有檔案上傳到 repo 根目錄（包含 `.nojekyll`）。
3. 進入 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/inkling/`。
5. 用手機開啟網址：iPhone 用 Safari「分享 → 加入主畫面」；Android 用 Chrome「安裝應用程式」。

## 取得 Gemini API 金鑰

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 登入並建立 API 金鑰。
2. 打開 app → 設定 → 貼上金鑰 → 按「測試連線」。
3. 預設模型是 `gemini-3.5-flash-lite`。模型改名或停用時，在設定裡換成其他名稱即可（例如 `gemini-flash-latest`）。

沒有金鑰時，可以在首頁點「先看範例批改」看完整的批改畫面。

## 本機測試

Service worker 需要 http 環境，不能直接雙擊 `index.html`：

```bash
cd inkling
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 檔案結構

```
index.html             頁面骨架與底部分頁
styles.css             視覺系統（色彩、字級、版面、深色模式）
app.js                 所有功能：畫面、AI 批改、文字差異、複習排程、資料存取
sw.js                  離線快取
manifest.webmanifest   PWA 安裝資訊
icons/                 App 圖示
```

## 發布更新

修改任何檔案後，把 `sw.js` 最上面的 `VERSION` 改成新版本號（例如 `inkling-v0.1.1`），使用者重新開啟 app 時就會拿到新版。

## 目前的限制（上架前要處理）

- **金鑰放在使用者的瀏覽器裡**：適合自己使用和找朋友測試。要給一般使用者用並收費，需要加一層後端代理（例如 Cloudflare Workers），由你保管金鑰、控管用量和訂閱。
- **資料只存在單一裝置**：換手機要靠匯出／匯入。之後可以加帳號與雲端同步。
- **隱私**：Gemini 免費方案的內容可能被 Google 用來改善模型，正式上線建議改用付費方案並在隱私權政策中說明。
- **自然朗讀**使用 Kokoro-82M（kokoro-js 1.2.1，Apache-2.0），提供 Heart 女聲與 Michael 男聲。首次使用需連線下載約 100 MB 模型及執行檔，之後盡可能使用瀏覽器快取；離線殼層不代表自然語音必定能離線啟動。低記憶體裝置可在設定改用裝置語音。
- Kokoro 在 Web Worker 以 WASM 執行，文字不會送往語音伺服器；模型與程式從 Hugging Face、jsDelivr 載入。長文分段播放，可隨時停止。設定提供試聽及 0.85×／1×／1.15× 語速。
- Service worker 更新只清除 Inkling 的舊版快取，保留 Transformers 模型快取。

## v0.2.1 語音預載與音訊快取

開啟 App 即在背景預載 Kokoro 模型，不需等到第一次朗讀。相同文字分段、聲音和語速重用本機 IndexedDB 音訊，重新開啟也可重用；音訊最多 32 MB，依最久未使用順序清理。儲存空間不足或瀏覽器停用 IndexedDB 時仍能朗讀，並保留最多 8 MB 的當次記憶體快取。瀏覽器清除網站資料或回收空間後，音訊會重新產生。

## v0.3.0 六種聲音、主題與語音輸入

自然語音提供 Heart／Bella／Nicole 女聲及 Michael／Fenrir／Puck 男聲，各聲音獨立快取。設定可選 Light、Dark 或 Auto；Auto 即時跟隨系統。首頁語音輸入使用麥克風錄音（最多 60 秒），轉成 WAV 後經既有 Gemini API 轉寫中英混說，保留繁體中文與英文，先預覽確認再加入草稿。需 API 金鑰、網路及麥克風權限；錄音不持久保存，取消會停止錄音與轉寫。

批改完成後先準備全文音訊，再開啟批改頁；單字、例句及修改句在結果頁顯示後於背景準備。等待期間顯示 App logo 動畫，不顯示音訊處理進度。若語音準備失敗，仍保留批改結果並允許點擊重試。背景準備與播放共用音訊快取，播放優先。

## v0.3.1 等待體驗

全文語音就緒即顯示批改結果，其餘語音接續在背景準備。已快取的播放不會等待背景推論；等待畫面使用既有 App logo 的呼吸、環繞與點點動畫，並遵守減少動態效果設定。
